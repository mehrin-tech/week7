1)aggregation pipeline:-
data-ne  step by step aayi process cheyth final reslt edukkunna mongoDB system aanu aggregation pipeline.

imagine you have a collection of studnts in mongoDB:
{
    name:"Ammeen",
    mark:55,
    department:"CS"
}

Find only CS students

Calculate average mark

Sort by highest mark

Group by department

Doing all this in one query = Aggregation Pipeline

it is a step by step data processing system

mongoDB sends data through multiple stages like a pipe line.each stages modifies the data and passes to next stage.

Q)Why do we use let in pipeline lookup?

Because in pipeline-based $lookup, the inner pipeline runs in the context of the foreign collection, so we must explicitly pass outer document fields as variables using let to compare them using $expr.

old datante koode new data  koode mix cheyyunnu.aggregation reslt existing collectionil safe ayyi,add/update cheyyan use chyyunnu.$out pole full delete cheyyilla.match cheyyum,upadte chyyum,illengil insert chryyum.

      into: "passed_students",
      on: "student_id",

      whenNotMatched: "insert"
    }
 }
 into → target collection

on → match cheyyan field

whenMatched: "merge" → update

whenNotMatched: "insert" → new insert

$merge is a terminal aggregation stage used to merge pipeline results into an existing collection with insert or update behavior instead of replacing it.
diff between $merge vs $out:-
Feature	                  $out    $merge
Old data delete cheyyumo?	Yes    	No 
Safe for production?	   Risky	  Yes
Update support undo?	   No	      Yes
Insert support undo?	   Yes	     Yes
